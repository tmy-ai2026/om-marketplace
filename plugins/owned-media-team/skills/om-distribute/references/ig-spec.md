# Instagram カルーセル spec の書き方

置き場所: 正本リポジトリの `claude/owned-media/social/ig_specs/<brand_id>_<slug>.json`
描画: `tools/make_social.py`(1080×1350 PNG・5枚・写真素材なし・ブランド色はアイキャッチ仕様と同一)

## 形式

```json
{
 "brand": "medinaturals",
 "slug": "cbd-oil-faq",
 "pr": false,
 "slides": [
  {"kind": "cover",   "title": "CBDオイル、買う前の6つの不安", "sub": "合法性・味・毎日の使用・依存性・運転・ドーピング検査"},
  {"kind": "body",    "label": "課題",  "title": "「CBDだから大丈夫」とは言えません", "body": ["決め手になるのは\nCBDかどうかではなく、\nΔ9-THCがどれだけ残っているかです。"]},
  {"kind": "body",    "label": "解決1", "title": "残留限度値は\n形状ごとに決まっている", "body": ["油脂・粉末 10ppm", "水溶液 0.10ppm", "その他 1ppm"], "note": "出典: 厚生労働省"},
  {"kind": "body",    "label": "解決2", "title": "…", "body": ["…"], "note": "※商品ページの表示値に基づく計算"},
  {"kind": "summary", "label": "まとめ", "title": "…", "body": ["…"], "cta": "続きはブログで → cbdmedia.tmy2026.com"}
 ]
}
```

| 項目 | 意味 |
|---|---|
| `brand` | `medinaturals` / `kurashite`(`make_social.py` の BRANDS のキー) |
| `slug` | 記事スラッグ。WordPress 上のファイル名 `<slug>-ig-1〜5.png` になる |
| `pr` | `true` で1枚目に「PR」バッジ。商品リンクを出す投稿(#PR を付けるもの)だけ |
| `rev` | 作り直すときだけ付ける(`2`, `3` …)。`<slug>-ig-N-r2` で別名登録される |
| `kind` | `cover`(1枚目)/ `body`(2〜4枚目)/ `summary`(5枚目・CTA ボタン付き) |
| `label` | 左上のラベル(課題 / 解決1 / 解決2 / まとめ) |
| `title` | 見出し。長ければ自動で縮小・改行 |
| `body` | 箇条の配列。2つ以上あると行頭に点が付く |
| `note` | 小さい灰色の注記。**出典・但し書きの指示がある画像案は必ずここに入れる** |
| `cta` | `summary` のボタン文言。ブログは「続きはブログで → <ドメイン>」、リンクを貼れない前提なら「続きはプロフィールのリンクから」 |

## 改行の手当て

自動改行は日本語の語の切れ目を知らないため、次が起きたら `\n` で手当てする。

- 語の途中で割れる(例: 「デ / メリット」「挙げ / ている」)
- 2文字以下の行が残る(例: 「不 / 安」)
- 行末に開き括弧が残る(例: 「…は「 / 濃度%」」)

`\n` を入れた見出しは、各行が1行に収まる最大の大きさで描かれる。

## 画像案から写すときの規則

- 画像案の文言を変えない(言い換え・盛りをしない)。長すぎて入らないときだけ、意味を変えずに分ける
- 数値を含む枚は、画像案の但し書き指示(「表示値に基づく計算」「一例」「出典: …」)を `note` に入れる
- 製品名・商品画像・購入先 URL は入れない(画像案で明示的に指示がある場合を除く)
