# om-marketplace

Cowork用の自作プラグインマーケットプレイス。

## 収録プラグイン

- **owned-media-team** v1.0.0 — オウンドメディアAI運用チーム(6ロールのスキル集)

## 使い方

Coworkの Customize → Plugins → 「+」→ Add marketplace → 「Add from a repository」で、このリポジトリ(`<GitHubユーザー名>/om-marketplace`)を指定 → 一覧に出てくる owned-media-team を Install。

プラグインを更新するときは `plugins/owned-media-team/` 配下を編集してpushし、Cowork側でマーケットプレイスを更新する。
